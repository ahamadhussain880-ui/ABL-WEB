# Student Web Development Projects

This repository contains three beginner-friendly website projects
created using **HTML and CSS**. They are suitable for a first-year
B.Tech student learning the basics of web development.

## Projects Included

### 1. ArenaX -- Gaming & Esports Website

**File:** `Gamingwebsite.html`

A dark-themed gaming community website for esports fans.

**Main sections** - Home and navigation menu - Featured games: Valorant,
League of Legends, Counter-Strike 2, and Clash of Clans - Upcoming
tournaments - Top player profiles - Team leaderboard - Latest gaming
news

**Design features** - Dark background with bright green highlights -
Flexible card layout using CSS Flexbox - Leaderboard table - Responsive
adjustments for smaller screens

### 2. DailyBrief -- Online News Portal

**File:** `Hussain News.html`

A simple online news portal that groups news topics into cards.

**Main sections** - Home - National news - International news - Sports -
Technology - Business - Education

**Design features** - Navy-blue header and orange navigation bar - News
cards with images, categories, headings, and descriptions - Flexible
layout using CSS Flexbox - Image alternative text (`alt`) for
accessibility

### 3. Travel Booking System

**File:** `train booking.html`

A student demonstration page for viewing sample bus and train schedules.

**Main sections** - Home and navigation menu - Booking details form
fields - Sample bus services - Sample train services - Seat
information - Contact information

**Design features** - Teal and yellow colour theme - Input fields and
dropdown lists - Tables and service information sections - Responsive
navigation and table spacing for small screens

**Important:** This is a front-end demonstration only. It does not book
tickets, calculate fares, select seats, or connect to a real booking
service.

## Technologies Used

-   **HTML5:** Builds the structure and content of each webpage.
-   **CSS3:** Controls colours, spacing, layouts, typography, and
    responsive styling.
-   **CSS Flexbox:** Arranges cards in flexible rows that can wrap onto
    new lines.

These projects do not require JavaScript in their current versions.

## How to Run the Projects

1.  Download or copy the three HTML files into one folder.
2.  Open the folder on your computer.
3.  Double-click an HTML file, or right-click it and choose a web
    browser.
4.  To make changes, open the file in a code editor such as Visual
    Studio Code.
5.  Save your changes and refresh the browser to see the updates.

## Learning Objectives

After studying these projects, a beginner can practise:

-   Creating a webpage with HTML elements
-   Organising content with headings, paragraphs, sections, and
    navigation links
-   Styling a page with CSS selectors and properties
-   Using classes and IDs
-   Creating cards and tables
-   Using Flexbox for layouts
-   Adding responsive CSS rules with media queries
-   Building simple front-end website demonstrations

## Limitations

-   The tournament, player, leaderboard, and news content is sample
    website content.
-   The news cards do not load full news articles; their "Read More"
    links point to sections within the page.
-   The travel page displays example schedules and contact details. It
    is not connected to a real transport provider.
-   No backend, database, user account system, or real booking/payment
    functionality is included.

## Conclusion

These three projects demonstrate basic HTML and CSS skills through
different website types: a gaming community, a news portal, and a travel
schedule interface. They can be extended later with JavaScript and
backend technologies as learning progresses.
